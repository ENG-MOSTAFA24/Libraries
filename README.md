# C++ Libraries

A collection of reusable C++ header libraries (classes) originally built for a bank client management system, along with sample data files used for testing/demo purposes.

## 📂 Repository Structure

### Libraries (Header Files)
| File | Description |
|---|---|
| `clsBankClient.h` | Core class for managing bank client data (balance, deposit, withdraw, etc.) |
| `clsDate.h` | Class for handling and manipulating dates |
| `clsInputValidate.h` | Class for validating user input |
| `clsPeriod.h` | Class for calculating and managing time periods |
| `clsString.h` | Class for string manipulation utilities |
| `clsUtil.h` | Class containing general-purpose helper functions used across the libraries |

### Sample Data Files
| File | Description |
|---|---|
| `Clients.txt` | Sample client records |
| `Users.txt` | Sample user records |
| `LoginRegister.txt` | Sample login/registration log |
| `TransferLog.txt` | Sample transfer log records |

## ✨ Features
- Reusable, self-contained header-only classes
- Input validation utilities
- Date and time-period handling
- String manipulation helpers
- File-based data handling examples (clients, users, login, transfers)

## 🛠️ Tech Stack
- **Language:** C++
- **Paradigm:** Object-Oriented Programming (OOP)
- **Storage (sample data):** Plain text files

## 📌 Notes
- These are standalone libraries meant to be reused across different projects, not a complete application.
